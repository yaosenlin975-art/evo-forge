# 代码审查评估标准 (Code Review Rubric)

> Darwin 技能家族共享的代码审查标准

## 审查评分体系（8维度，总分100）

| # | 维度 | 权重 | 审查内容 |
|---|------|------|---------|
| 1 | **安全性** | 20 | 注入风险、认证绕过、敏感信息泄露、硬编码密钥、SQL注入、XSS |
| 2 | **错误处理** | 15 | 空值处理、异常捕获、资源泄漏、边界条件、未处理返回值 |
| 3 | **代码规范** | 15 | 命名规范、函数长度、注释质量、格式一致性、导入顺序 |
| 4 | **性能** | 12 | 时间复杂度、资源占用、循环优化、缓存使用、数据库查询效率 |
| 5 | **可读性** | 10 | 逻辑清晰度、嵌套深度、魔法数字、复杂条件表达式 |
| 6 | **可维护性** | 10 | 耦合度、重复代码、硬编码、配置外化、依赖管理 |
| 7 | **测试覆盖** | 10 | 边界用例、异常路径、测试可读性、覆盖率 |
| 8 | **最佳实践** | 8 | 设计模式、语言特性使用、框架规范、并发安全 |

### 分数段对应

| 分数段 | 等级 | 说明 |
|--------|------|------|
| 90-100 | 🌟 优秀 | 代码质量极高 |
| 75-89 | ✅ 良好 | 基本无问题 |
| 60-74 | ⚠️ 及格 | 有改进空间 |
| 45-59 | ❌ 不及格 | 存在较多问题 |
| <45 | 🔴 危险 | 存在严重问题 |

---

## 严重程度分级

| 等级 | 标识 | 说明 | 处理建议 |
|------|------|------|---------|
| **Critical** | 🔴 | 必须立即修复，存在安全/严重bug | 立即处理，禁止上线 |
| **High** | 🟠 | 应尽快修复，影响稳定性 | 24小时内处理 |
| **Medium** | 🟡 | 建议修复，代码质量问题 | 计划迭代中处理 |
| **Low** | 🟢 | 可选改进，代码风格 | 有空时处理 |
| **Info** | 🔵 | 仅供参考 | 了解即可 |

---

## 支持的语言

| 语言 | 扩展名 | 特定规则 |
|------|--------|---------|
| Python | `.py` | PEP8、类型提示、docstring、虚拟环境 |
| C# | `.cs` | 命名规范、Dispose模式、async/await、LINQ |
| C++ | `.cpp`, `.cc`, `.h`, `.hpp` | RAII、智能指针、头文件保护、内存管理 |
| Lua | `.lua` | 全局变量检查、表操作、协程安全 |
| Java | `.java` | 命名规范、异常处理、资源管理、JVM优化 |
| JavaScript | `.js` | 变量提升、异步回调、ES6+特性 |
| TypeScript | `.ts`, `.tsx` | 类型检查、泛型、装饰器、模块系统 |
| Shell | `.sh`, `.bash` | 命令注入、变量引用、权限处理 |
| Go | `.go` | 错误处理、goroutine、接口设计 |
| Rust | `.rs` | 所有权、生命周期、Result处理 |
| Ruby | `.rb` | 命名规范、block使用、gem依赖 |
| PHP | `.php` | SQL注入、XSS、会话安全 |
