# 代码审查器 (evo-code-review)

> **EvoForge 子技能** | 版本: v1.1.0 | 父技能: evo-forge | 默认直接执行 ⚡

---

## 职责

对代码进行质量审查，识别问题、提出改进建议、输出审查报告。

---

## 触发词

| 模式 | 示例 |
|------|------|
| 审查 + 代码 | "审查代码" |
| review + 代码 | "review Python 代码" |
| 代码 + 问题 | "这段代码有什么问题" |
| 看看 + 代码 | "看看这个脚本" |
| 强化 + 代码 | "强化代码质量" |

---

## 双视角审查

### 🧬 专家视角

| 检查项 | 标准 |
|--------|------|
| **正确性** | 逻辑正确、无bug |
| **安全性** | 无注入、无泄露 |
| **性能** | 无明显性能问题 |
| **规范** | 符合语言最佳实践 |

### 😈 找茬视角

| 检查项 | 用户痛点 |
|--------|----------|
| **可读性** | 我能看懂吗？ |
| **可维护性** | 三个月后还能改吗？ |
| **容错性** | 异常情况会崩吗？ |
| **文档** | 有注释吗？文档在哪？ |

---

## 评分维度

| 维度 | 权重 | 检查内容 |
|------|------|----------|
| **正确性** | 25% | 逻辑、边界、异常处理 |
| **安全性** | 20% | 注入、泄露、敏感信息 |
| **可读性** | 20% | 命名、注释、结构 |
| **可维护性** | 15% | 重复、圈复杂度、耦合 |
| **性能** | 10% | 资源、算法复杂度 |
| **规范** | 10% | 语言惯例、风格统一 |

---

## 支持语言

| 语言 | 主要检查 |
|------|----------|
| Python | 类型注解、PEP8、异步 |
| JavaScript/TypeScript | ES6+、TS类型、安全 |
| C# | .NET规范、异步、LINQ |
| Shell/Bash | POSIX、安全、错误处理 |
| Go | 错误处理、并发模式 |
| Rust | 生命周期、所有权 |

## 审查流程

### Phase 0: 接收

1. 接收代码片段或文件路径
2. 识别语言
3. 确定审查范围

### Phase 1: 静态分析

1. 语法检查
2. 圈复杂度计算
3. 重复代码检测
4. 安全扫描

### Phase 2: 双视角审查

**🧬 专家视角**
- 正确性：边界条件
- 安全性：潜在风险
- 性能：算法效率

**😈 找茬视角**
- 可读性：命名清晰度
- 容错性：异常处理
- 可维护性：模块化程度

### Phase 3: 精简验证与输出

#### 3.1 语句精简验证
审查报告同样需要精简，确保可读性：

| 原则 | 说明 |
|------|------|
| 每条问题一句话 | 问题描述不超过一行，详情放入建议列 |
| 合并同类问题 | 同一类问题合并为一条，用"多处"标注 |
| 删评价性废话 | 去掉"看起来"、"似乎"、"可以认为"等模糊措辞 |
| 评分评语精简 | 总分评语控制在 2-3 句话，每维度评语不超过 1 句 |
| 保持技术准确 | 行号、风险等级、建议代码片段不变 |

#### 3.2 输出报告

## 输出报告格式

```markdown
## 🔍 代码审查报告

### 基本信息
| 项目 | 值 |
|------|-----|
| 语言 | Python |
| 行数 | 156 |
| 复杂度 | 8 (中等) |

### 问题列表

#### 🔴 严重问题
| 位置 | 问题 | 建议 |
|------|------|------|
| L23 | SQL注入风险 | 使用参数化查询 |

#### 🟡 建议改进
| 位置 | 问题 | 建议 |
|------|------|------|
| L45 | 函数过长(80行) | 拆分为多个函数 |

### 评分
| 维度 | 分数 |
|------|------|
| 正确性 | 18/25 |
| 安全性 | 12/20 |
| 可读性 | 16/20 |
| 可维护性 | 10/15 |
| 性能 | 8/10 |
| 规范 | 7/10 |
| **总分** | **71/100** |

### 总结
- ✅ 优点：...
- ❌ 问题：...
- 💡 建议：...
```

---

## 问题严重性分级

| 级别 | 标记 | 说明 | 处理 |
|------|------|------|------|
| **严重** | 🔴 | 安全性/正确性问题 | 必须修复 |
| **警告** | 🟡 | 可维护性/性能问题 | 建议修复 |
| **提示** | 💡 | 代码风格/最佳实践 | 可选改进 |

---

## 禁止事项

| ❌ 禁止 | 原因 |
|--------|------|
| 修改用户代码 | 仅审查，不修改 |
| 强制要求重构 | 权衡成本收益 |
| 引入新问题 | 建议需验证可行性 |
